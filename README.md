# 🌷 loan_approval_ml

A machine learning project for **loan approval prediction**. ✿

The project compares several classification algorithms to predict whether a loan application should be **approved or rejected**, with data preprocessing, model training, evaluation, and saved `.pkl` models.

### 🌱 Model Performance

| Model                  | Test Accuracy |
| ---------------------- | ------------: |
| 🌳 Random Forest       |    **97.89%** |
| 🌿 Decision Tree       |    **97.65%** |
| 🌱 Gradient Boosting   |    **97.30%** |
| 🌸 AdaBoost            |    **96.72%** |
| ✿ Extra Trees          |    **96.01%** |
| 🐇 Gaussian NB         |    **93.91%** |
| 🌷 SVC                 |    **93.79%** |
| 🍃 KNeighbors          |    **91.92%** |
| 🌼 Logistic Regression |    **90.51%** |

**Best test accuracy:** Random Forest — **97.89%**

🛠️ Technologies Used
Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Joblib · Jupyter Notebook
